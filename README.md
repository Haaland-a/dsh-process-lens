# 过程讲解器（dsh-process-lens）

[![DSH plugin](https://img.shields.io/badge/DSH-plugin-4f7cff)](https://github.com/Haaland-a/dsh-process-lens)
[![version](https://img.shields.io/badge/version-0.2.4-2ea043)](./package.json)
[![license](https://img.shields.io/badge/license-MIT-blue)](./LICENSE)
[![self test](https://img.shields.io/badge/self--test-58%2F58-2ea043)](./harness.mjs)

把 AI 干活的每一步摊开给你看：**原文点一下就看全文**（不花额度），**人话解说按需生成**（点哪步才讲哪步），**用哪个模型讲由你单独挑**。

它回答的是那个最常冒出来的问题：*"这半天它到底在忙什么？"*

---

## 一、你要的几件事

### 1. 讲解员可以单独选模型

插件有自己的一条模型路由，**不跟主对话绑在一起**。

- 打开面板 → 设置区「讲解模型」下拉框 → 选供应商 + 模型；
- 默认 `跟随会话（deepseek / chat）` 会实时显示主对话现在用的是哪个，方便对照；
- 选完立刻生效，下一个要讲的步骤就用新模型；右边「刷新」可重新读一遍模型列表；
- 下拉框的提示 `只影响讲解，不影响会话本身用的模型` 就是它的边界。

省钱的一般做法：主对话用强模型干活，讲解模型挑一个又便宜又快的。

### 2. 花不花额度、看哪几轮，你自己点

**默认一个字都不自动讲。** 打开面板只是把原文摊出来，一次模型调用都没有。

| 你想干的事 | 点哪儿 | 花多少 |
| --- | --- | --- |
| 看它这一步到底做了什么 | 卡上「▸ 展开原文」，展开是**全文**：完整思考、完整参数、完整返回、它说的话 | 0 |
| 只看某一步的人话解释 | 那张卡右下角 `讲这步` | 1 次 |
| 把这一轮还没讲的都讲一遍 | 面板顶部 `全部讲一遍（N 步）`，N 是还没讲过的步数 | N 次 |
| 想重讲 | 讲过的卡按钮变 `再讲一次` | 1 次 |

讲过的步骤会标成 `讲完了`，「全部讲一遍」自动跳过它们，不重复烧钱。

**打开时显示 N 步**（设置区第三行，默认 8）：一进来只摆最近 N 步，省得一屏刷不完、也方便直接看最新的；上面有一行 `上面还有 X 步没摆出来 · 展开这一轮全部 Y 步`，点一下全给，再点 `收起` 回到最近 N 步。**不会只给你 3 步**——想看多少有多少，只是默认先摆最近的。

「自动弹出」开关（默认关）：开了以后只要出现新一轮就把面板摊出来——**摊出来也只是给你看原文，不会自动讲**。

**打开时自动讲 N 步**（设置区第四行，默认关）：开了以后，每次你打开面板，插件会自动把**最近 N 步**（默认 3，可填 1–20）翻成人话概要摆出来，你点开就有东西看，不用一步步点「讲这步」。代价是每次打开都花 N 次模型调用；已经讲过的步会被跳过，不会重复收钱。

- 关着（默认）：一打开只显示原文，一分不花，想看哪步点哪步。
- 开着：打开即有概要；同一轮里已经讲过的不会再讲，重新打开时只补没讲过的。
- 想临时只讲一步：不管这个开关，直接点那张卡的「讲这步」。

### 3. 反馈只说人话

每张卡两层：上面是**默认折叠的原文**（点开就是全文，不是节选），下面是三行人话：

```
标题      改配置读取顺序
在做什么   把默认档和立即档的判断先后调了个头，先看有没有人在看
结果      改完了，现在默认不花额度
```

- 工具名翻成人话：`grep` → 搜代码，`write` → 写文件，`pwsh` → 跑命令……
- 失败会标红并写明原因（`权限不足`、`文件不存在`……），不是甩一串堆栈。
- 讲失败也不静默：卡上直接写 `这次没翻译出来，可以再点一次`。

### 4. 面板尺寸

右下角浮动，**620 宽 × 面板高度的 74%（上限 780px）**，避开窗口右上角的 − □ ×；正文 13px，原文块可以滚动，长内容不再挤成一条。

### 4.5 两个标签：过程 / 设置

面板顶上分出两页，不用再在过程上面挤一排开关：

- **过程**：你让它做的事、这一轮的每一步、讲这步 / 全部讲一遍；
- **设置**：外观、讲解模型、自动弹出、显示几步、自动讲、讲解口味、提示词存档。

设置页自己会滚，提示词预览再长也整段看得到（之前「提示词显示不全」就是这么修掉的）。

### 4.6 要不要它先思考（默认关）

设置页第二行是「让它思考」开关，**默认关**：

| 状态 | 实际发生什么 |
| --- | --- |
| 关（默认） | 不传思考档位里偏高的那些，能拿到 none / off / minimal 就用它，拿不到就用最低档；回答更快、更省额度 |
| 开 | 不干预档位，让模型用自己默认的那一档先想再写；讲得更细，但慢一些、更费额度（预算会自动抬到 2400 token 起，避免还没写完就被截断） |

一句话：平时关着够用；哪一步实在看不懂，再打开让它多想一会儿。

### 4.7 过程页：最近 N 步 / 全部（老会话也能看全）

过程页顶上有个小开关：**「最近 N 步」 / 「全部 M 步」**。

- 刚进来默认「最近 N 步」（N 在设置里改，默认 8），屏幕不炸；
- 点「全部 M 步」就把这一轮每一步都摆出来，**选完会记住**，下次打开还是你选的那个；
- 中间还有一条「上面还有 X 步没摆出来 · 展开这一轮全部 Y 步」，点一下同样切到全部。

以前已经结束的老会话（甚至 DSH 重启过的那种）只显示最后几步，是因为补账只回放最近 4000 条事件——
现在点开某一轮时，插件会**从这一轮的 turn/start 重新回放**，把整轮补齐（每一轮只补一次，不重复花钱也不重复算）。

### 5. 讲解风格 / 自己的提示词 / 省 token

这三样都在面板设置区的「讲解口味」里：

**总结风格**：四档预设，只换说法不换格式（永远是「标题 / 在做什么 / 结果」三行）：

| 档位 | 讲出来是什么味 |
| --- | --- |
| 通俗（默认） | 像同事给你顺一遍：它想干嘛、动了哪里、成没成 |
| 专业 | 面向技术负责人，点出机制和判断依据 |
| 一句话 | 只给结论，一行说完 |
| 给新手 | 解释每个名词，假设你不熟这套工具 |

**自己的提示词**：

- 「看当前提示词」→ 预览**真正发出去的两段文本**（系统提示 + 这一步的实际内容）和字数；
- 「新建存档」→ 写要求、起个名字（比如「给老板看」「只要结论」），存成存档；名字随便起，改删都行；
- 存档会出现在风格下拉的「我的存档」里，随时切回内置档；
- 存自己的提示词也不会破格式——插件会把三行格式要求追加在末尾。

**省 token 模式**：

- 打开后只把**最近 N 步压成要点**再发给模型（N 默认 5，可 1–50，旁边有 5 / 10 快捷按钮）；
- 提示里会明写「省 token 模式：信息已压缩」，模型知道自己在看摘要，不会瞎编细节；
- **只有真的更短才用压缩版**：内容本来就短的步骤，压缩版为了带上「最近 N 步概要」反而更长，
  所以插件把两种都算一遍，谁短发谁——开了省 token 绝不会更费；
- **省了多少你能直接看见**：
  - 预览里写「共 X 字 · 不省是 Y 字，实际省了 Z%」；
  - 每张卡片「展开原文」旁边写「提示词 N 字」，那是这一步真正发给模型的长度；
  - 实测肥步骤：不省 4248 字 → 省后 1361 字（省 68%）；
- 关掉就是原来的完整内容。长会话想省钱就开它。

**外观 / 主题**（设置页最上面）：

| 档位 | 效果 |
| --- | --- |
| 跟随壁纸（默认） | 和 DSH 深浅色、以及你装的 dsh-wallpaper 那套插件同步：底色跟着壁纸走，面板是半透明玻璃，换壁纸换色调这里一起变 |
| 浅色 | 固定白底，关掉模糊，字最清楚 |
| 深色 | 固定深底，关掉模糊，夜里不刺眼 |

怎么和壁纸插件配合的：面板优先读壁纸插件的玻璃变量（--we-panel-color / --we-blur / --we-saturate / --we-accent），
读不到就退回宿主自己的令牌（--dsw-alias-*）；固定浅 / 深两档会**就地覆盖**身边这一圈令牌，
所以里面的卡片、按钮、滚动条会一起变色，不会出现「外壳换了、里面还是旧色」的花脸。
没装壁纸插件也能正常用，只是没有玻璃感。

## 二、三个入口在哪儿

| 位置 | 长什么样 | 干什么 |
| --- | --- | --- |
| 每条回答下方 | 小按钮「过程」 | 看这一轮的过程（最常用） |
| 输入框下面 | 小按钮 `看过程` | 不离开对话就能看最新一轮 |
| 页面浮层 | 右下角浮动面板 | 「过程」页看步骤、逐条点讲；「设置」页选模型、外观、提示词 |

面板里可以一路往下翻历史轮次——**插件装上之前的轮次也能看**（会从会话自己的事件流里回放补账，不需要你重新问一遍）。

## 四、遇到问题

| 现象 | 怎么办 |
| --- | --- |
| 点「过程」提示「刷新一次页面」 | 浏览器半更新了，`Ctrl+R` |
| 提示「插件后端没在跑」 | 重启 DSH，或在插件页重新启用一次 |
| 模型下拉里只有「跟随会话」 | 面板里点「刷新」；仍为空会直接显示读不到的原因 |
| 卡片上只有标题没有原文 | 正常，原文默认折叠，点「▸ 展开原文」 |
| 只看到最近几步 | 默认摆最近 N 步（设置里可改），点「展开这一轮全部」看全 |
| 关掉又自己弹出来 | v0.2.1 已修：手动关掉后本轮不再自动弹；也可以按 Esc，或再点一次回答下的「过程」收起 |
| 讲解很慢 | DeepSeek 思考档位高，插件已自动降到最低档；换更小的模型更快 |
| 风格改了但没变 | 卡片是之前讲好的，点「再讲一次」才会用新风格重讲 |
| 提示词预览是空的 | 这个会话还没有步骤记录，预览给的是样例文本（会标「样例」） |
| 开了省 token 细节变少 | 正常，它就是拿细节换额度；关掉即恢复 |
| 开了省 token 字数没变 | 这步内容本来就短，压缩版会更长，插件自动按原文发（预览里会直说） |
| 老会话只显示最后几步 | v0.2.4 已修：点开那一轮会把整轮回放补齐；再看还是少，说明那几步在 DSH 里就没记录 |
| 切了「全部」下次又变回 N 步 | 不会，这个选择存在设置里；除非清过 process-lens.json |
| 找不到选模型的地方了 | 在「设置」标签页里，不再占过程页的地方 |
| 选了浅色 / 深色但看着没变 | 这两档是固定的；点「跟随壁纸」才会跟壁纸和系统深浅走 |
| 面板没有玻璃感 | 没装壁纸插件（或那套插件没开），退回宿主默认底色，功能不受影响 |
| 提示词还是显示不全 | 设置页要往下滚；预览区已经不再限高，整段都在 |
| 开了思考后变慢 | 正常，它在先想再写；嫌慢就关掉，或者换个更小的模型 |
| 开着思考还是很快 | 那个模型可能压根没提供思考档位，插件不会硬塞 |

## 五、实现要点（给以后的自己看）

- **Host 半**：监听 `session/event` 记账（轮次、步骤、工具调用、思考、回答），
  `GET /process-lens/stream`（SSE）推送 `snap` / `card` / `turn` / `ping`；
  `GET|POST /process-lens/api/*` 处理配置、模型目录、轮次定位、快照与讲解请求。
- **原文全文**：`cardOf()` 的 `raw = { thinking, answer, actions[{name,label,detail,args,state,output}] }`，
  文本统一用 `FULL_CHARS = 20000` 截（实际等于不截），`tool.result` 记账时也不再用 `oneLine` 压平，
  只有喂给讲解模型的那份 prompt 才走 `REASONING_CHARS / ANSWER_CHARS / RESULT_CHARS` 的节选。
- **花钱闸门**：`enqueue(sessionId, turn, step, force)`——`force !== true` 时只把状态标 `idle` 并推一帧，
  **绝不排队**。只有 `POST /explain` 走 `enqueue(..., true)`；SSE 连上只算「看」，不算「讲」。
  `/explain` 不传 `step` 时过滤掉 `done / running / queued`。
- **打开时显示 N 步**：`settings.recent`（默认 8，1–100），前端只 slice 后 N 步渲染，另给「展开全部」按钮；
  这是纯前端行为，不影响 host 记账，也不影响讲解。
- **讲解预算**：并发 2，单次 60 秒超时，`maxTokens` 默认 1600；
  `llm.stream` **不能传 `purpose`**（`LlmRequestPurpose` 是 `never`），
  且必须显式取 `resolveModelInfo().reasoning.efforts` 的最低档，否则思考会把预算吃光。
- **历史补账**：第一次被问到某会话时，回放 `session.snapshotEvents()` 末尾 4000 条事件；
  回放期间**不触发**讲解。
- **风格 / 提示词**：风格决定了 system prompt 的人设段（`STYLE_PRESETS`），
  内置格式要求单独放 `OUTPUT_RULES`，无论选哪档、用谁的自定义提示词，
  最后都会把这一段拼上去，所以三行格式不会被玩坏。
  自定义存档存进 settings.prompts（id 用 `p + base36 时间`，name ≤ 40 字，text ≤ 4000 字），
  `activePrompt` 指向哪条就用哪条；删掉当前项会自动回到内置风格。
- **预览**：`GET /process-lens/api/prompt?session=` 直接用 `buildPrompt()` 生成真实内容，
  不是拼一份假的给你看；会话还没步骤时给样例并标 `sample: true`。
- **省 token**：拆成 `buildPromptFull()` / `buildPromptCompact()`，`buildPrompt()` 只在
  `settings.compact === true` 且**压缩版真的更短**时才用压缩版（否则退回完整版，保证不变费）。
  压缩版：诉求截 120 字、每步压成一句 `briefOfStep`、思考 240 / 回答 200 / 工具 detail 80 / result 100 且最多 6 个，
  末尾补一句「看清楚的就讲，看不清的别猜」。
- **字数可见**：`runJob()` 把 `promptText.length` 记到 `entry.promptChars`，`cardOf()` 输出成 `chars`；
  `GET /prompt` 额外算一遍完整版给 `fullChars` 和 `compactUsed`，前端据此显示省了多少 / 是否回退。
- **老会话补齐**：`hydrateTurn(sessionId, turn)` 在完整事件里倒着找这一轮的 `turn/start`，
  从那儿回放到末尾（普通 `hydrate()` 只看末尾 `MAX_REPLAY = 4000` 条）；`deepHydrated` Set 保证每轮只扫一次。
  `/snapshot` 与 `/explain` 都会先调它。
- **显示多少步**：`settings.allSteps`（默认 false）。前端过程页顶部的「最近 N 步 / 全部」直接写这个开关，
  所以选了会记住；`recent` 仍是 N。
- **标签页**：`state.tab`（`'process'` / `'settings'`）放在全局 store 里，切换只换渲染分支；
  过程页那一段外面套了 `.pl-frag { display: contents }`，这样它还是抽屉的 flex 子元素，
  滚动和拉伸跟以前一样。设置页是 `.pl-pane`（`flex:1; min-height:0; overflow:auto`），自己滚，
  所以 `Settings + PromptStudio` 再长也不会被抽屉的 `overflow:hidden` 裁掉——顺手把
  `.pl-pre { max-height: 200px }` 在设置页里放开了。
- **思考开关**：`settings.thinking`（默认 false）。关时 `lowestEffort()` 照旧挑最低档（优先
  none/off/minimal），开时直接返回 undefined 不传 `reasoningEffort`，让模型走自己的默认档；
  同时 `maxTokens` 抬到至少 2400，防止思考把预算吃光、正文被截断。
- **主题**：`settings.theme`（auto / light / dark）由 Host 校验后回传，前端写到抽屉根的 `data-pl-theme`。
  auto 不动任何令牌，只读 `--we-*` 做玻璃；light / dark 在 `.pl-drawer[data-pl-theme=...]` 上覆盖
  `--dsw-alias-bg-*` / `--dsw-alias-label-*` / `--dsw-alias-border-l*` / `--dsw-alias-brand-primary`，
  并把 `--we-blur` 置 0、关掉 backdrop-filter，保证字够清楚。
- **鉴权**：路由统一过 `ctx.get('connection').requestRejection(req)`。
- **设置持久化**：`<DSH_PROFILE_DIR>/process-lens.json`。

## 六、自测

```bash
node harness.mjs
```

用假 ctx 跑 **58 条**断言：历史补账、messageId→轮次定位、工具人话标签、原文（含参数/返回）随卡返回、失败标红、
「只连流不点 = 0 次模型调用」、显式点讲才 1 次且用插件自己选的模型、讲失败会标 `failed` 并推流、
「全部讲一遍」跳过讲过的、`recent` 默认值与上下限、`autoSummarize` 开关与 1–20 上限、
四种讲解风格、系统提示里确实带三行格式要求、预览里是这一步的真实内容、
省 token **真的更短**（4248 → 1361 字）且没丢用户诉求、预览会给「不省时多少字」、
老会话点开某一轮能补齐全部 6 步、过程页「最近 N 步 / 全部」存得住、
自定义提示词的存 / 切 / 删、外观三档（默认跟随、存深色、乱值被忽略、存浅色）、
思考开关（默认关、开、只认真假、再关）。不联网、不花额度。
